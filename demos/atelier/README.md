# ATELIER — sitio demo para arquitectura

Landing page profesional para un **estudio ficticio de arquitectura**. Construida con HTML5, CSS y JavaScript sin dependencias de compilación.

## Funcionalidades

- Navegación responsive con menú móvil y secciones claras.
- Galería de cuatro proyectos conceptuales con filtros por categoría.
- Diseño editorial, composición visual e imágenes de referencia.
- Formulario validado que abre una consulta prellenada en WhatsApp; no almacena ni envía datos automáticamente.
- Diseño accesible con etiquetas, atributos ARIA y preferencia de movimiento reducido.

**Importante:** ATELIER es un proyecto de demostración de Gonzalo Martínez. No representa una empresa existente, proyectos construidos ni clientes reales. Las imágenes se cargan desde Unsplash y requieren conexión.
