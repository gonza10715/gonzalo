# VELOCE Motors — concesionaria ficticia

Web de presentación de vehículos premium con filtros para deportivos y SUV, tarjetas de modelos ficticios y formulario que prepara una consulta de desarrollo web por WhatsApp. No se venden automóviles y los valores son ilustrativos.

## Stack
HTML5, CSS3 y JavaScript; diseño responsive, navegación móvil y controles accesibles. No requiere proceso de compilación.

## Uso
Abrí `index.html` en un navegador. Para compartirla, usá la [demo pública](https://gonza10715.github.io/gonzalo/demos/veloce/).

**Portfolio ficticio de Gonzalo Martínez.** Las imágenes externas se usan como referencia visual y requieren conexión a Internet. No representa trabajos encargados por clientes reales.
