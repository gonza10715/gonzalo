04 / Preguntas frecuentes

Todo más simple.

¿Puedo pedir un turno real desde esta página?

No. Este es un sitio de demostración para el portfolio de Gonzalo Martínez. El formulario solo muestra cómo funcionaría el proceso en una clínica real.

¿Se guardan mis datos?

No. Esta demo no tiene base de datos ni envía los valores del formulario a un servidor.

¿Se puede adaptar esta web a una clínica real?

Sí. Se puede reemplazar la información ficticia, integrar una agenda real y configurar servicios, sedes y medios de contacto.
