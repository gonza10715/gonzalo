# Portfolio de Gonzalo Martínez

Portfolio técnico personal con proyectos de HTML, CSS, JavaScript, Python, Flask y SQLite.

## Incluye
- Presentación de perfil técnico y tecnologías.
- Enlaces a repositorios propios y a demos de proyectos comerciales.
- Contacto por WhatsApp.
- Diseño responsive sin dependencias.

## Ejecutar
Abrí `index.html` en el navegador. Los enlaces relativos a otras demos funcionan si se mantiene la estructura de carpetas `demos/`.

## Nota
Los proyectos listados son prácticas propias y demos. No se presentan como trabajos de clientes reales.
