# SERENA Casa Hotel — alojamiento ficticio

Landing boutique con habitaciones conceptuales, simulador local de estadía y formulario de contacto comercial para contratar desarrollo web. No admite reservas ni procesa pagos.

## Stack
HTML5, CSS3 y JavaScript; diseño responsive, navegación móvil y controles accesibles. No requiere proceso de compilación.

## Uso
Abrí `index.html` en un navegador. Para compartirla, usá la [demo pública](https://gonza10715.github.io/gonzalo/demos/serena/).

**Portfolio ficticio de Gonzalo Martínez.** Las imágenes externas se usan como referencia visual y requieren conexión a Internet. No representa trabajos encargados por clientes reales.
