# Casa Brava — demo de restaurante

Proyecto de portfolio de **Gonzalo Martínez**.

Landing page para un restaurante ficticio con:
- Identidad visual cálida y diseño responsive.
- Carta con filtros interactivos por categoría.
- Secciones de marca, menú y contacto comercial.
- Enlace de WhatsApp del desarrollador para pedir una web similar.

## Ejecutar
Abrí `index.html` en un navegador. No requiere instalación ni dependencias.

## Alcance
**Es una demostración ficticia.** No recibe reservas, pedidos ni pagos. No se utilizan datos comerciales reales.
