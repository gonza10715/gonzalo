# Norte Studio — tienda online de demostración

Proyecto de portfolio de **Gonzalo Martínez**.

- Catálogo ficticio de productos con búsqueda y categorías.
- Carrito interactivo con cantidades, eliminación y total.
- Botón de compra **simulada**: no hay pagos, pedidos ni almacenamiento de datos.
- Diseño responsive sin dependencias.

## Ejecutar
Abrí `index.html` en un navegador.

## Tecnologías
HTML5, CSS3 y JavaScript.

**Importante:** precios y artículos son ficticios. No es una tienda operativa.
