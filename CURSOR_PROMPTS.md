# Prompts para trabajar GM Web con Cursor Agents

Repositorio: `gonza10715/gonzalo`

## Reglas permanentes
- Trabajá en una rama nueva para cada mejora y abrí un pull request.
- No borres archivos ni cambies el sitio principal sin describir el impacto.
- No contrates servicios, no uses APIs pagas y no solicites datos bancarios.
- Considerá todas las marcas, productos y reservas de `demos/` como ficticios.
- Usá HTML semántico, CSS responsive y JavaScript sin dependencias, salvo necesidad real.
- Verificá teclado, contraste, pantallas móviles y enlaces.
- Probá el código antes de entregar; indicá qué pruebas se ejecutaron y cuáles no.
- Mantené los mensajes comerciales honestos: los formularios de demostración no deben aparentar ventas reales.

## Prompt 1 — revisar GM Web
Revisá `index.html`, `style.css`, `app.js` y las páginas de `demos/`. Buscá errores funcionales, enlaces rotos, problemas de usabilidad móvil y accesibilidad. Proponé y aplicá mejoras pequeñas en una rama. No cambies el número de WhatsApp ni las condiciones comerciales. Adjuntá capturas de escritorio y móvil si tu entorno lo permite. Abrí PR con el resumen y las pruebas.

## Prompt 2 — mejorar Casa Brava
Mejorá la demo `demos/restaurante/index.html` para convertirla en una landing de restaurante de alto nivel, manteniendo el menú interactivo y la advertencia de que es una demostración ficticia. Agregá imágenes optimizadas con derechos de uso adecuados si es posible, navegación accesible y una sección de horarios ilustrativos claramente marcada como demo. No simules reservas reales. Probá filtros, responsive y accesibilidad.

## Prompt 3 — mejorar Norte Studio
Mejorá `demos/tienda/index.html`. Agregá controles de cantidad del carrito, opción de ordenar productos y persistencia local opcional sin almacenar datos personales. No integres pasarelas de pago ni pidas datos de tarjetas. Verificá que totales y filtros sean correctos, y creá una PR.

## Prompt 4 — portfolio técnico
Revisá `demos/portfolio/index.html` y sus enlaces. Mejorá su presentación para postulaciones junior de HTML/CSS/JavaScript/Python/Flask. No inventes experiencia, títulos, clientes ni empleos. Mostrá tecnologías solo si constan en los proyectos o fueron declaradas por Gonzalo. Asegurá que todas las demos tengan enlaces funcionales. Abrí PR y adjuntá pruebas.

## Prompt 5 — nuevo proyecto
Creá una nueva demo en `demos/turnos/`: sistema de turnos para barbería ficticia, sin backend y sin reservas reales. Permití elegir servicio, fecha y hora disponibles desde datos de ejemplo, y mostrar un resumen final como simulación. Diseño profesional responsive. Incluí README y pruebas básicas. No cambies la web principal hasta que la demo funcione.
